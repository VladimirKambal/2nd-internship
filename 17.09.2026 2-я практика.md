### Часть 1. Сеттеры с валидацией

**Задача:** Добавить в класс `Book` возможность обновлять данные книги с проверкой корректности.

1. **Добавьте приватный метод `isValidData()`:**
    
    
    ```cpp
    
    bool isValidData(std::string title, std::string author, int year, int pages) const;
    ```
    
    Метод должен проверять:
    
    - `title` и `author` не пустые
        
    - `year` находится в диапазоне от 1450 (изобретение печатного станка) до 2025
        
    - `pages` больше 0
        
2. **Добавьте публичные сеттеры:**
    
    
	```cpp
    void updateTitle(std::string new_title);
    void updateAuthor(std::string new_author);
    void updateYear(int new_year);
    void updatePages(int new_pages);
    ```
    **Важно:** Каждый сеттер должен:
    
    - Проверять новое значение через `isValidData()`
        
    - Если значение невалидно — выбрасывать `std::invalid_argument` с понятным сообщением
        
    - Если валидно — обновлять соответствующее поле
        
3. **Протестируйте в `main.cpp`:**
    
    - Создайте книгу
        
    - Попробуйте обновить год на 3000 — должно выброситься исключение
        
    - Обработайте исключение через `try`/`catch`
        
    - Успешно обновите название книги
        

**Подсказка:** Не забудьте добавить `#include <stdexcept>` в `book.cpp`.

### Часть 2. Методы vs свободные функции

Теперь вам нужно решить, где должна жить логика для следующих операций. Для каждой операции:

- **Решите:** должна ли она быть методом класса `Book` или свободной функцией?
    
- **Обоснуйте:** использует ли операция внутреннее состояние объекта? Является ли она частью основной ответственности класса?
    
- **Реализуйте:** выбранный вариант.
    

**Операция 1: Форматирование информации о книге**

Функция должна возвращать строку в формате:

```text

"Title: <title>, Author: <author>, Year: <year>, Pages: <pages>, Status: <Available/Checked Out>"
```

**Вопрос:** Это метод или свободная функция? Почему?

**Операция 2: Проверка, является ли книга классикой**

Книга считается классикой, если она опубликована более 50 лет назад (до 1975 года).

**Вопрос:** Это метод или свободная функция? Почему?

**Операция 3: Вычисление "скорости чтения"**

Функция принимает количество страниц, которое читатель прочитывает в день, и возвращает, за сколько дней будет прочитана книга.


```cpp

double readingTime(int pages_per_day);
```

**Вопрос:** Это метод или свободная функция? Почему? Обратите внимание: функция не использует состояние книги напрямую, только количество страниц.

**Операция 4: Сравнение двух книг по году издания**

Функция принимает две книги и возвращает `true`, если первая книга старше второй.

**Вопрос:** Это метод или свободная функция? Почему?

**Подсказка для размышления:**

- Если функция использует только геттеры и не зависит от внутреннего состояния — скорее всего, это свободная функция.
    
- Если функция является частью "поведения" книги (например, `checkout()`, `returnBook()`) — это метод.
    
- Форматирование, сравнение, вычисления на основе внешних данных — обычно свободные функции.
